# لاسِلكي 📻 — لاسلكي رقمي عبر Wi-Fi المحلي

تطبيق Push-to-Talk حديث يعمل **بدون إنترنت تمامًا**: الأجهزة على نفس شبكة Wi-Fi تكتشف بعضها تلقائيًا وتتحدث صوتًا مباشرة (P2P عبر WebRTC) بضغطة زر واحدة.

> **سرعة + استقرار + جودة صوت + بساطة + جمال + خصوصية + موثوقية**

---

## المنصات الثلاث — وكيف تتصل

| المنصة | المجلد | الدور | الميكروفون |
|---|---|---|---|
| 🌐 **ويب (PWA)** | `src/` (كود Next.js) | يعمل من أي متصفح، قابل للتثبيت كتطبيق على أندرويد/ويندوز | ✅ عبر HTTPS (المعاينة السحابية أو أي مضيف HTTPS) |
| 🪟 **ويندوز** | `desktop-windows/` | تطبيق سطح مكتب + **مضيف الشبكة** (يشغّل خدمة الاكتشاف والواجهة) | ✅ كامل |
| 📱 **أندرويد** | `mobile-android/` | تطبيق APK أصلي يتصل بالمضيف عبر عنوان الشبكة المحلية | ✅ كامل |

### سيناريو الاستخدام المثالي على شبكة منزلية
1. شغّل تطبيق **ويندوز** على الحاسوب — هو يصبح المضيف ويعرض رمز QR للانضمام.
2. افتح تطبيق **أندرويد** وأدخل عنوان الحاسوب (مرة واحدة — يحفظه ويتصل تلقائيًا).
3. تحدث فورًا — الصوت ينتقل مباشرة بين الجهازين، والحاسوب فقط أدار "دليل الهاتف" في البداية.
4. أي عدد إضافي من الأجهزة (ويندوز/أندرويد/متصفح) يظهر تلقائيًا في قائمة الجميع.

### جربها الآن بلا تثبيت
افتح رابط المعاينة على جهازين (متصفح الحاسوب + هاتف على نفس الشبكة) — كل شيء يعمل: اكتشاف، اتصال، حديث، موجات صوتية، وقياس كمون لحظي.

## البناء

| الهدف | الخطوات |
|---|---|
| 🪟 تطبيق ويندوز (مثبّت + نسخة محمولة) | انقر `desktop-windows\build-windows.bat` — خطوة واحدة |
| 📱 تطبيق أندرويد (APK) | افتح `mobile-android/android` في Android Studio → Build APK |
| 🌐 خادم ويب ذاتي الاستضافة | `npm install` ثم `npm run build` ثم `npm start` (منفذ 3000 + خدمة إشارة 3003) |

الأدلة التفصيلية داخل كل مجلد: `desktop-windows/README-AR.md` و `mobile-android/README-AR.md`.

## البنية التقنية

```
┌─────────────────────────────────────────────────────┐
│                  نفس شبكة Wi-Fi                     │
│                                                     │
│   [ويندوز Electron]──┐                        ┌──[أندرويد APK]│
│    مضيف: واجهة:3000  │      الصوت WebRTC      │  WebView + ميكروفون │
│    إشارة:3003 ───────┼◄── P2P مباشر ──────────►│                 │
│                      │   (لا يمر عبر الخادم)   └─────────────────┘
│   [متصفح PWA]────────┘         ▲                      ▲
│    عبر http://host:3000        └──── اكتشاف عبر socket.io (3003)
└─────────────────────────────────────────────────────┘
```

- **الاكتشاف**: خدمة إشارة socket.io (`mini-services/signaling`) — حضور الأجهزة + تمرير عروض WebRTC فقط.
- **الصوت**: WebRTC P2P — Opus مع FEC + DTX و32kbps، `playoutDelayHint=0`، وPTT عبر `track.enabled` بلا إعادة تفاوض (استجابة لحظية).
- **قناة تحكم** (DataChannel): بدء/إيقاف الحديث + قياس زمن الاستجابة كل ثانيتين.
- **المتانة**: ICE Restart تلقائي، إعادة اتصال عند عودة الجهاز، Wake Lock أثناء المحادثة، حماية من تكرار الجهاز.
- **الخصوصية**: لا حسابات، لا تحليلات، الصوت لا يغادر الشبكة المحلية أبدًا، هوية محلية على الجهاز فقط.

## الخصوصية والأمان
- الصوت مشفّر ضمن قنوات WebRTC (DTLS-SRTP) ولا يُخزَّن ولا يُسجَّل.
- خدمة الإشارة تنقل بيانات تعريف فقط: اسم الجهاز، الأفاتار، حالة الاتصال.
- خيار «طلب الإذن قبل الاتصال» يمنع أي جهاز من فتح قناة معك دون موافقتك.
