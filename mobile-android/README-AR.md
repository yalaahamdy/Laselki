# لاسِلكي — تطبيق أندرويد 📻📱

تطبيق أندرويد أصلي (Capacitor) يغلّف واجهة **لاسِلكي** بدعم كامل للميكروفون،
ليتحدث مع تطبيق ويندوز وأي أجهزة أخرى على نفس شبكة Wi-Fi — بدون إنترنت وبدون حسابات.

---

## كيف يعمل؟

1. عند فتح التطبيق تظهر شاشة «الاتصال بالشبكة».
2. أدخل عنوان جهاز الاستضافة (الحاسوب الذي يشغّل تطبيق ويندوز لاسِلكي) مثل `192.168.1.10` — يُحفظ تلقائيًا ويتصل تلقائيًا في المرات القادمة.
3. تفتح واجهة اللاسلكي الكاملة داخل التطبيق: رادار اكتشاف، أجهزة قريبة، زر حديث ضخم.
4. عند أول ضغط على زر الحديث سيطلب أندرويد إذن الميكروفون — اسمح به مرة واحدة.

> 💡 اتجاه العنوان: يظهر أيضًا في تطبيق ويندوز ضمن لوحة **رمز QR**.

---

## المتطلبات للبناء

| المتطلب | ملاحظات |
|---|---|
| [Android Studio](https://developer.android.com/studio) (أحدث إصدار) | يتضمن SDK وJDK المطلوبين |
| هاتف بأندرويد 8.0+ (للتجربة) | أو محاكي — لكن الميكروفون الحقيقي أفضل على هاتف فعلي |

> مجلد `android/` **جاهز ومولّد مسبقًا** — لا حاجة لتنفيذ أي أوامر Capacitor قبل الفتح.

---

## بناء APK بخطوتين

### 1) افتح المشروع في Android Studio
```
File → Open → اختر مجلد mobile-android/android
```
انتظر حتى تنتهي مزامنة Gradle (أول مرة فقط، يحتاج إنترنت).

### 2) شغّل أو ابْنِ
- **للتجربة المباشرة:** اضغط زر ▶ (Run) والهاتف موصول بـ USB مع تفعيل USB Debugging.
- **لإنتاج APK:**
```
Build → Build App Bundle(s) / APK(s) → Build APK(s)
```
سيظهر الرابط: `android/app/build/outputs/apk/debug/app-debug.apk`

انسخه للهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة» عند الطلب).

> 🏪 لإصدار متجر (AAB موقّع): `Build → Generate Signed Bundle / APK` وأنشئ مفتاح توقيع خاصًا بك.

## حل المشكلات

| المشكلة | الحل |
|---|---|
| «عنوان غير صالح» في شاشة الاتصال | أدخل عنوان IPv4 فقط مثل `192.168.1.10` أو مع منفذ `192.168.1.10:3000` |
| الأجهزة لا تظهر بعد الاتصال | تأكد أن الهاتف والحاسوب على نفس شبكة Wi-Fi وأن تطبيق ويندوز يعمل |
| لا يوجد صوت من الهاتف | تحقق من إذن الميكروفون: إعدادات أندرويد → التطبيقات → لاسِلكي → الأذونات → الميكروفون |
| فشل مزامنة Gradle | تحقق من اتصال الإنترنت، وFile → Sync Project with Gradle Files |
| تغيّر عنوان الحاسوب | عدّل العنوان في شاشة الاتصال (تظهر عند إعادة فتح التطبيق) |

## ملاحظة تقنية للاتصال

شاشة الاتصال تحوّل WebView إلى `http://<العنوان>:3000/?signal=<العنوان>:3003`:
- المعامل `?signal=` يخبر محرك اللاسلكي بموقع **خدمة الإشارة** (المنفذ 3003 على نفس الجهاز المضيف) ويُحفظ محليًا.
- تم تمكين `usesCleartextTraffic` و`allowNavigation` للسماح بالاتصال المحلي غير المشفّر داخل التطبيق.
- الميكروفون يعمل داخل WebView عبر أذونات `RECORD_AUDIO` + `MODIFY_AUDIO_SETTINGS` المضافة في الـ Manifest.

## بنية المجلد

```
mobile-android/
├── capacitor.config.ts   ← إعدادات Capacitor (allowNavigation, https scheme)
├── www/index.html        ← شاشة «الاتصال بالشبكة» (محفوظة داخل APK)
├── android/              ← مشروع أندرويد جاهز للفتح في Android Studio
│   └── app/src/main/
│       ├── AndroidManifest.xml   (أذونات الميكروفون + الشبكة)
│       └── res/                  (أيقونات لاسِلكي + شاشة بداية مولّدة)
└── package.json          ← أدوات Capacitor (للمزامنة عند تعديل www)
```

> بعد أي تعديل على `www/` شغّل: `npm install` ثم `npx cap sync android`
