# لاسِلكي — تطبيق ويندوز 📻

تطبيق سطح مكتب احترافي يعمل كـ **جهاز لاسلكي كامل + مضيف شبكة** في نفس الوقت.
شغّله على حاسوبك المنزلي، وستنضم إليه بقية الأجهزة (أندرويد / ويندوز / متصفح) عبر شبكة Wi-Fi المحلية مباشرة — بدون إنترنت وبدون خوادم سحابية.

---

## ماذا يفعل التطبيق عند التشغيل؟

1. يشغّل **خدمة الإشارة** داخل العملية نفسها (المنفذ `3003`) — جهازك يصبح مركز اكتشاف الأجهزة.
2. يشغّل **خادم الواجهة** (المنفذ `3000`) كعملية مستقلة.
3. يفتح نافذة التطبيق بنفس تجربة الهاتف: رادار اكتشاف، زر حديث ضخم، موجات صوتية حية.
4. يعرض في لوحة «انضم من جهاز آخر» رمز QR بعنوان شبكتك المحلية الحقيقي (وليس localhost).

> 🔊 **الصوت لا يمر عبر الحاسوب** — ينتقل مباشرة (P2P) بين الأجهزة المتحادثة عبر WebRTC، حتى لو كان الحاسوب هو من شغّل خدمة الاكتشاف.

## المتطلبات

| المتطلب | ملاحظات |
|---|---|
| Windows 10 أو أحدث (64-bit) | — |
| [Node.js LTS](https://nodejs.org) (18+) | للبناء فقط — التطبيق النهائي لا يحتاجه |
| اتصال إنترنت عند البناء أول مرة | لتنزيل Electron والاعتماديات |
| السماح للتطبيق في جدار الحماية | عند أول تشغيل اختر «السماح» على الشبكات الخاصة |

---

## البناء بخطوة واحدة

1. حمّل مجلد المشروع كاملًا (يحتوي هذا المجلد بجانب كود الواجهة).
2. انقر نقرًا مزدوجًا على:

```
desktop-windows\build-windows.bat
```

3. انتظر — السكربت ينفّذ كل شيء تلقائيًا:
   - تثبيت الاعتماديات وبناء واجهة Next.js (وضع standalone)
   - نسخ ملفات الخادم داخل مجلد التطبيق
   - تجميع خدمة الإشارة إلى ملف واحد
   - إنتاج ملفات التثبيت في `desktop-windows\dist`:
     - **لاسِلكي Setup.exe** — مثبّت عادي
     - **لاسِلكي-Portable.exe** — نسخة محمولة بلا تثبيت

### تجربة سريعة قبل التثبيت

```bat
cd desktop-windows
npm start
```

## انضمام الأجهزة الأخرى

### هاتف أندرويد (الطريقة المثلى)
استخدم **تطبيق أندرويد المرفق** (مجلد `mobile-android`) — أدخل عنوان الحاسوب الظاهر في لوحة QR مثل `192.168.1.10` واضغط اتصال. يعمل بالميكروفون كاملًا كتطبيق مستقل.

### متصفح على أي جهاز بنفس الشبكة
افتح `http://<عنوان-الحاسوب>:3000` — يمكنك رؤية الأجهزة والاستماع.

> ⚠️ **ملاحظة تقنية مهمة:** متصفحات Chrome/Edge تمنع الميكروفون على العناوين غير المشفّرة (http) لاعتبارات أمان — لذلك **الحديث من المتصفح على شبكة محلية** محدود بينما يعمل كاملًا في تطبيقي ويندوز وأندرويد المرفقين، وكذلك عبر رابط المعاينة السحابية (HTTPS). لتفعيل الحديث من المتصفح محليًا مستقبلًا يمكن إضافة شهادة HTTPS محلية (mkcert مثلًا).

### جهاز ويندوز ثانٍ
ثبّت نفس التطبيق عليه — سيتصلان تلقائيًا على نفس الشبكة (أحدهما يكفي كمضيف).

## حل المشكلات

| المشكلة | الحل |
|---|---|
| «Windows protected your PC» عند التثبيت | اختر More info → Run anyway (التطبيق غير موقّع رقميًا) |
| الأجهزة لا تظهر | تأكد أن الحاسوب والهاتف على نفس شبكة Wi-Fi، واسمح للتطبيق في جدار الحماية للشبكات **الخاصة** |
| المنفذ 3000/3003 مشغول | أغلق التطبيق الآخر المستخدم للمنفذ، أو أعد تشغيل الحاسوب |
| فشل `npm install` | تأكد من تثبيت Node.js LTS وأعد فتح نافذة CMD ثم أعد المحاولة |
| صوت لا يصل بين جهازين | تحقق أن كليهما متصل بنفس التطبيق المضيف (نفس الشبكة) وأن الميكروفون مفعّل |

```

├── bundle-signaling.mjs  ← تجميع خدمة الإشارة (esbuild)
├── build-windows.bat     ← بناء كامل بخطوة واحدة

├── resources/icon.png    ← أيقونة التطبيق
└── server/               ← (يُنشأ عند البناء) خادم Next.js standalone
```
